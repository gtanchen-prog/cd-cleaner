C盘清理助手 v1.5 使用说明
============================================================

一、运行环境
  · Windows 10 / 11（系统自带 .NET Framework 4.8，无需安装其他组件）
  · 免安装绿色版：整个文件夹可拷贝到任意位置（桌面、D盘、U盘均可）
  · 双击 CdCleaner.exe 或“启动清理助手.bat”，首次运行会弹出 UAC
    提示，点“是”获得完整清理权限（点“否”则以受限模式运行）

二、界面与主题
  · 右上角“主题”下拉框：
      跟随系统 —— 自动跟随 Windows 的浅色/深色（系统主题变化时实时切换）
      浅色     —— 固定浅色
      深色     —— 固定深色（窗口标题栏、列表也会变深）
  · 主题选择会记住，下次启动自动恢复
    （保存在 %LOCALAPPDATA%\CdCleaner\settings.ini）
  · 主题切换已做防闪烁处理（整窗重绘一次，不闪屏）

三、使用方法
  1. 在“驱动器”中勾选要清理的盘（影响回收站与各盘 Temp）
     · 上方“全选驱动器”复选框：一键全选/取消全选，部分勾选时显示“部分选中”状态
     · 旁边“反选”按钮：勾选状态整体取反
  2. 在“清理项目”中勾选要清理的类别（默认全选）
     · 上方“全选清理项目”复选框同样支持全选/取消全选，并实时跟随下方列表状态
     · 旁边“反选”按钮：勾选状态整体取反
  3. 点“扫描大小”预览各项目体积（可选）
  4. 点“开始清理”，右下日志实时显示每一步的进度与释放量，
     结束后自动弹出“清理结果汇总”（总释放量、各项明细、用时）
  5. 清空回收站：点红色按钮，弹窗中会显示每个盘的回收站文件数与
     体积，勾选“我明白此操作不可恢复”后才能确认

四、托盘与定时任务（v1.2 新增）
  · 托盘：点窗口最小化按钮 → 窗口隐藏到系统托盘，双击托盘图标恢复；
    托盘右键菜单可“打开界面 / 立即清理缓存 / 退出”。
    点窗口右上角 X 会直接退出程序。
  · 定时自动清理：点“定时自动清理…”按钮 →
      勾选“启用每周自动清理”，选择星期与时间，保存即可。
    程序会创建 Windows 计划任务 CdCleanerWeeklyClean，按设定时间
    在后台静默清理缓存（不弹窗、不需要登录界面操作），结果写入
    “清理日志.txt”。取消勾选并保存即可删除该计划任务。
    注意：定时任务只清理缓存类项目，不会清空回收站、不会改系统设置；
    创建/删除计划任务需要管理员权限。

五、清理范围（只清缓存 / 临时 / 冗余文件）
  系统缓存：
    · 系统临时文件（Windows\Temp）
    · Windows 更新下载缓存
    · 预读取缓存（Prefetch）
    · 系统错误报告（WER）
    · 内存转储（Memory.dmp / Minidump / LiveKernelReports）
  用户缓存：
    · 用户临时文件（管理员模式下含所有用户的 Temp）
    · 浏览器缓存：Chrome / Edge / Brave / Chromium / Vivaldi /
      Opera / Firefox 的全部配置文件（Cache、Code Cache、
      GPUCache、Service Worker 缓存等）
    · 缩略图 / 图标缓存
    · DirectX 着色器缓存
    · 应用崩溃转储（CrashDumps）
    · 用户错误报告（WER）
    · 应用缓存（Packages\*\LocalCache）
  驱动器：
    · 各盘根目录 Temp
    · 回收站（必须单独确认，默认不会自动清理，定时任务也不含）

六、不会触碰的内容
  系统文件、页面文件、休眠文件、系统还原点、WinSxS、Installer、
  系统日志，以及文档 / 桌面 / 下载 / 图片 / 视频 / 音乐 /
  OneDrive 等个人资料。程序内置路径白名单与保护规则，即使配置
  出错也不会删除个人目录或盘符根目录。

七、日志
  程序目录下“清理日志.txt”记录每次操作（时间戳 + 操作 + 释放量）。
  界面上“打开日志”可直接查看；若程序目录只读，会自动改存到
  %LOCALAPPDATA%\CdCleaner\清理日志.txt。

八、常见问题
  Q: 双击 EXE 后没有窗口？
  A: 如果 UAC 弹窗被取消，程序会以受限模式继续（部分系统项目跳过）；
     若完全没反应，检查杀毒软件是否拦截。
  Q: 标题栏显示“受限模式”？
  A: 没有拿到管理员权限。退出后右键程序 → “以管理员身份运行”，
     或在 UAC 弹窗中选“是”。
  Q: 最小化后找不到窗口？
  A: 看屏幕右下角系统托盘，双击绿色圆形图标恢复。
  Q: 定时任务没执行？
  A: 打开“任务计划程序”查看 CdCleanerWeeklyClean 的上次运行结果；
     确认计算机在设定时间处于开机状态（默认仅登录时运行）。
  Q: 某些文件清不掉？
  A: 文件正被程序占用（例如浏览器缓存被运行中的浏览器锁定）。
     关闭对应程序后再清理即可。
  Q: 支持 Windows 7 吗？
  A: 不支持。需要 Windows 10 / 11（.NET Framework 4.8）。
